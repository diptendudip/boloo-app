───────────────────────────────────────────────────────────────
  🚀 QUICK START COMMANDS
───────────────────────────────────────────────────────────────

Install & Setup:
  npm install -g eas-cli
  eas login
  eas init

Build:
  npm run build:android        # APK (testing)
  npm run build:android:aab    # AAB (Play Store)
  npm run build:ios            # IPA (App Store)
  npm run build:all            # Both platforms

Submit:
  npm run submit:android       # Play Store
  npm run submit:ios           # App Store
  npm run submit:all           # Both stores

Update (OTA):
  npm run update               # JavaScript updates only
